# Petal

**انقر بزر الفأرة الأيمن على ملف. اختر الصيغة. اكتمل التحويل.**

Petal أداة أصلية لنظام Windows 11 تجمع تحويل الصور والصوت والفيديو والمستندات النصية في قائمة دائرية صغيرة. تعمل في مستكشف الملفات وعلى سطح المكتب، وتتبع سمة Windows ولون التمييز، وتتيح فتح قائمة Windows الأصلية من الزر الأوسط.

هذه الصفحة بالعربية. **واجهة التطبيق باللغة الإنجليزية حاليًا.**

## معاينة

![قائمة Petal الدائرية وتأثير المرور والتحميل وعلامة النجاح](../media/demo.gif)

أُنشئت المعاينة باستخدام محرّك الرسم الأصلي واسم ملف تجريبي. [كيفية إنشاء الصور](../MEDIA.md) (بالإنجليزية).

## المزايا

- ستة خيارات مناسبة كحد أقصى؛ تُستبدل صيغة الملف الحالية بخيار آخر.
- تحويل محلي للصور والصوت والفيديو والمستندات النصية، دون رفع الملفات.
- سمة **Liquid glass** افتراضية: البتلات والدائرة الوسطى زجاج مصنفر يكسر ما خلفه ويتفتح بحركة فقاعة، مع سمة كلاسيكية تتبع لون تمييز Windows.
- مؤشر تحميل وعلامة نجاح وإشعار Windows يحمل الشعار وصوت يمكن تعطيله.
- تطبيق أصلي بلغة Rust يستخدم Win32/GDI+، دون بيئة تشغيل متصفح.

> **يبقى الملف الأصلي دون تغيير.** يتحقق Petal من النتيجة ويحفظ نسخة في المجلد نفسه بالامتداد الجديد: `photo.jpg` → `photo.webp`. لا يستبدل أي ملف موجود. قد تختلف البيانات الوصفية أو تنسيقات النسخة المحوّلة.

## الصيغ

| الملف المحدد | الخيارات الافتراضية | بديل الصيغة الحالية |
| --- | --- | --- |
| صورة | JPG · PNG · WebP · GIF · BMP · PDF | TIFF |
| صوت | MP3 · WAV · FLAC · M4A · OGG · MP4 | OPUS |
| فيديو | MP4 · MKV · WebM · MOV · MP3 · WAV | AVI |
| مستند نصي | TXT · DOCX · MD · HTML · RTF · PDF | ODT |

تحويل الصوت إلى MP4 ينشئ فيديو بخلفية سوداء وصوت الملف. وتحويل الفيديو إلى MP3 يستخرج المسار الصوتي. يحافظ تحويل المستندات على النص والفقرات، وليس التنسيق الأصلي. ملفات PDF الممسوحة ضوئيًا تتطلب OCR ولا تُقبل حاليًا. راجع [الصيغ والقيود](../../FORMATS.md) بالإنجليزية.

## البدء

**المتطلبات: Windows 11 x64.**

### تنزيل v1.2.1

نزّل **[Petal.exe](https://github.com/Syawi/Petal/releases/download/v1.2.1/Petal.exe)** وشغّله مباشرة على Windows 11 x64. لا تحتاج إلى ZIP أو مجلد موارد أو صلاحيات مسؤول أو Office.

الشعار والصوت والتراخيص مضمّنة. تُحفظ ملفات التشغيل في `%LOCALAPPDATA%/Petal`. عند أول تحويل للصوت أو الفيديو يُنزَّل محرّك FFmpeg تلقائيًا مع التحقق منه (حوالي 109 MB)، ثم تعمل التحويلات دون اتصال. لا تحتاج الصور والمستندات إلى هذا التنزيل.

يُفعّل البدء مع Windows عند أول تشغيل ويمكن تعطيله من **Settings**. أبقِ الملف التنفيذي في موقع ثابت. التراخيص متاحة عبر **Settings → Licenses**.

### البناء من المصدر

ثبّت [Rust](https://rustup.rs/) وأدوات بناء Visual Studio C++ وWindows SDK لسلسلة MSVC، ثم نفّذ:

```powershell
git clone https://github.com/Syawi/Petal.git
cd Petal
./Build.ps1
./Petal.exe
```

يجهّز السكربت FFmpeg/FFprobe، ويتحقق من SHA-256 للتنزيل، ويشغّل الاختبارات، وينشئ الملف التنفيذي. لتعليمات GNU، راجع [CONTRIBUTING.md](../../CONTRIBUTING.md) بالإنجليزية.

## استخدام القائمة

1. شغّل `Petal.exe`. يظهر الشعار الأزرق في منطقة الإعلام، وقد يكون ضمن الأيقونات المخفية.
2. اضغط **Shift** وانقر بزر الفأرة الأيمن على ملف مدعوم في المستكشف أو على سطح المكتب.
3. اختر صيغة. ينشئ Petal النسخة ويتحقق منها ثم يعرض **Conversion complete**.

يفتح الزر الأوسط (شعار Windows) القائمة الأصلية، كما يفعل النقر العادي بزر الفأرة الأيمن. الاختصار الافتراضي لفتح Petal هو **Shift مع النقر بزر الفأرة الأيمن** ويمكن تخصيصه. انقر خارج القائمة أو اضغط **Esc** لإخفائها؛ يستمر التحويل الجاري في الخلفية.

| الاختصار | الإجراء |
| --- | --- |
| `1`–`6` | التحويل باستخدام البتلة المقابلة |
| `Tab` ثم `Enter` / `Space` | تحديد خيار وتفعيله |
| `M` | فتح قائمة Windows السياقية |
| `Esc` | إخفاء القائمة أو مؤشر الحالة |

افتح **Settings…** من أيقونة منطقة الإعلام لتسجيل مفتاح أو زر فأرة مع Ctrl/Shift/Alt/Win، وضبط البدء مع Windows، واختيار صوت WAV ومعاينته. تُحفظ التغييرات تلقائيًا، ويعيد **Reset** الاختصار الافتراضي.

النقر بزر الفأرة الأيسر على أيقونة منطقة الإعلام يفتح الإعدادات السريعة (Liquid glass وAnimations وSound و**All settings…**). من قائمة النقر بزر الفأرة الأيمن، يعطّل **Mute sound** الصوت، ويفتح **Settings…** نافذة الإعدادات الكاملة، ويغلق **Quit Petal** التطبيق. يُحفظ تفضيل الصوت. لا يتاح الخروج أثناء التحويل.

## المظهر والتطوير

![Petal بسمتي Liquid glass والكلاسيكية، داكنة وفاتحة](../media/themes.png)

**Liquid glass** (افتراضية): زجاج مصنفر عديم اللون يكسر ما خلف القائمة، ويضيء عند مرور المؤشر بلمعة بيضاء وحافة أكثر سطوعًا. **Classic**: أسطح Windows 11 معتمة، وتمتلئ البتلة بلون التمييز عند المرور ويصبح النص أسود. تتبع السمتان الوضع الفاتح أو الداكن في Windows. يمكن تغيير السمة وتشغيل الحركة أو إيقافها من الإعدادات.

```powershell
./Install-MediaEngine.ps1
cargo fmt --check
cargo test --locked
cargo build --release --locked
```
